# Contributing to SaneSales

Thanks for helping. SaneSales is free MIT software.

## Quick start

```bash
git clone https://github.com/sane-apps/SaneSales.git
cd SaneSales
xcodegen generate
./scripts/SaneMaster.rb verify
```

## Good first work

- Fix a labeled `help wanted` issue
- Improve setup copy so a first-time seller knows what to connect
- Add tests around a provider parser or a settings row that is hard to find

Do not add a paywall. Donate stays optional.

## Requirements

- Xcode 16+
- macOS 15 to build; the app runs on macOS 14+ / iOS 17+
- [XcodeGen](https://github.com/yonaskolb/XcodeGen)
